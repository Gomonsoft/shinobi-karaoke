# 0036 — API IPC del runtime, solicitud de cierre y bloqueo de navegación durante la instalación
- Estado: Hecha
- Paso del pipeline: 0
- Depende de: 0011, 0021, 0034
- ADRs: 0006, 0008, 0009
- Spec UX: docs/ux/01-primer-arranque.md (criterios 1, 6, 8); docs/ux/03-anadir-cancion.md (aviso de duración: estimación)

## Objetivo
Exponer al renderer el gestor de runtime con el contrato tipado de 0011 y resolver dos piezas de main que la vista necesita: confirmar el cierre de la ventana durante la instalación y no permitir salir del primer arranque por menú o atajos.

## Criterios de aceptación
- [ ] Contrato en `shared/ipc.ts` + `canales.ts` + handlers + preload (validado con Zod y con la comprobación de remitente de 0021):
  - `runtime.estado()` → `{ estado: 'verificando' | 'pendiente' | 'en_curso' | 'completa' | 'dañada', fases, error, perfilPrevisto, perfil, motivoRebaja, modo, bytesRestantes }`.
  - `runtime.requisitos({ recalcularEspacio })` → resultado de `requisitosPrevios()` (0031), **ampliado** con el motivo de no tener plataforma (decisión del arquitecto, 2026-11-04, `preguntas/0017` "Cambios que necesita la tarea 0037" §2; lo consume 0037 para elegir B6 o B6b):
    - `motivo: null | 'arquitectura' | 'so_antiguo'`. `null` si `plataforma !== null`. `'arquitectura'`: la combinación SO + arquitectura **real** no está en el manifiesto (Windows/Linux arm64, ia32, cualquier Mac Intel, SO desconocido). `'so_antiguo'`: la combinación sí está en el manifiesto pero la versión del SO es menor que el mínimo (hoy solo `darwin-arm64` con macOS < 14).
    - `versionMinimaSo: null | { version: string, nombre: string | null }`: solo con `motivo === 'so_antiguo'` (`{ version: '14', nombre: 'Sonoma' }`); `null` en el resto. El renderer **no** repite el mínimo ni el nombre: compone `pa.macos.cuerpo` ("14 (Sonoma)") con estos datos y con `equipo.versionSo`.
    - **Orden de la decisión** (`ux/01` B6b): primero la presencia en el manifiesto, después la versión. Un Mac Intel con macOS 13.6 da `motivo: 'arquitectura'`, nunca `'so_antiguo'`.
    - Afecta a `app/src/main/runtime/deteccion.ts`: la tarea **0034 (en curso)** ya implementa ahí la regla macOS < 14 (`MACOS_MINIMO = 14`, `plataformaActual(real, manifiesto, versionSo)` devuelve `null`), pero hoy comprueba la versión **antes** que el manifiesto y no dice el motivo. En esta tarea: `plataformaActual` (o una función nueva `evaluarPlataforma`) devuelve `{ plataforma, motivo, versionMinimaSo }` con el orden de arriba; `RequisitosPrevios` y su esquema Zod del contrato IPC incluyen los dos campos; el nombre "Sonoma" vive junto a `MACOS_MINIMO` en main. 0034 sigue usando `plataforma === null` → `PLATAFORMA_NO_SOPORTADA` sin cambios.
    - Tests: `darwin-arm64` 13.6 → `{ plataforma: null, motivo: 'so_antiguo', versionMinimaSo: { version: '14', nombre: 'Sonoma' } }`; 14.0 → `darwin-arm64`, `motivo: null`; `darwin-x64` 13.6 y 15.1 → `motivo: 'arquitectura'`, `versionMinimaSo: null`; Linux arm64 → `'arquitectura'`; versión ilegible en Mac arm64 → `'so_antiguo'` (se trata como antigua, como hoy).
  - `runtime.instalar()` (también sirve para Reintentar/Continuar/Reparar), `runtime.pausar()`.
  - `runtime.alProgreso(cb)` (canal `runtime:progreso`, ≤ 4/s) y `runtime.alCambiar(cb)` (cambios de fase/estado/error).
  - `runtime.detalles()` → texto para "Copiar detalles": versión de la app, SO, fase, código de error y últimas 50 líneas del registro del runtime (`ux/01` criterio 8).
  - `runtime.estimarSeparacion(duracionMs)` → `{ min, max }` en minutos con `estimarMinutosSeparacion` (0029) y el perfil/modo vigentes (lo usan B3 y el aviso de canción larga de `ux/03`).
- [ ] **Solicitud de cierre**: mientras `estado === 'en_curso'`, el evento `close` de la ventana se intercepta y main envía `app:solicitudCierre` al renderer; el renderer responde con `app.confirmarCierre()` (main llama a `pausar()` y cierra) o no hace nada. Sin instalación en curso, el cierre es el actual (0021). Diseñado para reutilizarlo en la Fase 3 (diálogo de cierre con trabajos, `ux/04` §3).
- [ ] Durante el primer arranque (estado distinto de `completa`) se ignoran las acciones del menú nativo "Añadir canción" y "Ajustes" y sus atajos (`ux/01` criterio 1); el resto del menú (Edición, zoom, Salir) funciona. "Salir" del menú en macOS pasa por la solicitud de cierre.
- [ ] El texto de detalles no incluye rutas absolutas del usuario fuera del directorio de datos (se sustituyen por `<datos>`).
- [ ] **Lista blanca de enlaces** (`ENLACES_PERMITIDOS` en `shared/ipc.ts`, ADR 0008 punto 8): se añade `{ host: 'support.apple.com', prefijoRuta: '/es-es/108382' }` (página oficial de Apple "Actualizar macOS en el Mac", en español, comprobada el 2026-11-04; botón "Cómo actualizar macOS" de B6b, 0037). Solo esa ruta exacta, no todo `support.apple.com`. Test de `enlacePermitido`: acepta `https://support.apple.com/es-es/108382`, rechaza `http:`, otra ruta (`/es-es/108383`) y otro host.
- [ ] Tests: handlers (validación de argumentos, remitente), solicitud de cierre (con instalación en curso se pide confirmación; sin ella no), menú ignorado durante el primer arranque; `e2e/ipc.spec.ts` actualizado con las claves nuevas.

## Notas de implementación
- **Qué se hizo**: contrato `runtime.*` y `app.confirmarCierre` en `shared/ipc.ts` (esquemas Zod `estadoRuntimeSchema`, `requisitosRuntimeSchema`, `progresoRuntimeSchema`, `estimacionSeparacionSchema`), `canales.ts`, handlers y preload (`window.shinobi.runtime` y `window.shinobi.app.{confirmarCierre, alSolicitudCierre}`). Eventos `runtime:progreso` (≤ 4/s, lo limita el gestor), `runtime:cambio` y `app:solicitudCierre`. `ENLACES_PERMITIDOS` incluye solo `support.apple.com/es-es/108382`.
- **Archivos clave**: `main/runtime/servicio.ts` (fachada: estado persistido + vivo, bytes restantes, detalles, estimación, `ocultarRutas`), `main/runtime/composicion.ts` (`crearRuntimeReal`: manifiesto, detección, uv real, gestor y servicio; **0035 debe reutilizar `runtime.gestor` y `runtime.servicio.fijarVerificando()`** en `index.ts`, no crear otro gestor), `main/runtime/deteccion.ts` (`evaluarPlataforma` → `{ plataforma, motivo, versionMinimaSo }`, `NOMBRE_MACOS_MINIMO = 'Sonoma'`; `RequisitosPrevios` lleva `motivo` y `versionMinimaSo`), `main/cierre.ts` (`crearControlCierre`, reutilizable en la Fase 3), `main/menu.ts` (parámetro `permitida`), `main/index.ts` (cableado).
- **Decisiones**: `runtime.instalar()` responde al momento y el resultado llega por `alCambiar`/`estado()`. `en_curso` guardado sin proceso vivo se muestra como `pendiente`. `verificando` lo fija 0035 con `fijarVerificando(true/false)`; el estado `dañada` ya existe en la config. `recalcularEspacio` no cambia nada porque `requisitosPrevios()` ya relee el espacio libre en cada llamada. `estimarSeparacion` devuelve `null` sin perfil o sin datos. En detalles, el directorio de datos, la carpeta personal y cualquier `/Users/x`, `/home/x`, `C:\Users\x` se sustituyen por `<datos>`; el registro del runtime son las últimas 50 líneas `[runtime]` de `app.log`. Con instalación en curso, Salir (Cmd+Q/menú) pasa por `before-quit` y la solicitud de cierre; sin solicitud previa, `confirmarCierre` no hace nada. El menú ignora "Añadir canción"/"Ajustes" mientras `completa()` sea falso (también durante `verificando`).
- **Cómo probarlo**: `cd app && npx vitest run src/main/runtime src/main/cierre.test.ts src/main/menu.test.ts src/main/ipc` y `npx playwright test e2e/ipc.spec.ts`.
- **Verificación**: typecheck, lint, format:check y vitest completo (893 pasan) en verde; build OK. Playwright: 13 pasan; fallan 5 de `e2e/importar-archivo.spec.ts` (tarea 0046, ajena) porque en este equipo no hay `uv` en el PATH.
- **Deuda**: no hay prueba E2E del diálogo de cierre ni del primer arranque real (llegan con 0037/0039); la vista que consume `app.alSolicitudCierre` es 0037.
