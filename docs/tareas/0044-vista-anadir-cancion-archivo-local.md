# 0044 — Vista Añadir canción: archivo local (y arrastrar a la Biblioteca)
- Estado: Hecha
- Paso del pipeline: 1
- Depende de: 0042, 0043 (y 0036 solo para la cifra del aviso de canción larga: si aún no está, se deja el aviso sin cifra y se completa al integrar)
- ADRs: 0003, 0006
- Spec UX: docs/ux/03-anadir-cancion.md (wireframes A y D, origen "Archivo", criterios 1–3, 9–12, 14); docs/ux/02-biblioteca.md (arrastrar archivo, criterio 9)

## Objetivo
Sustituir el marcador de la vista 03 por la vista real para archivos locales, incluida la importación real del archivo arrastrado sobre la Biblioteca (deuda de 0020), y el resumen editable del paso 1 de una canción existente.

## Criterios de aceptación
- [ ] `vistas/anadir/`: cabecera de 0043 en modo nueva; selector de origen (control segmentado) con "Archivo de tu equipo" por defecto (la pestaña YouTube llega en 0051; hasta entonces el selector puede ocultarse); zona de arrastre de 640 × 240 con los estados de `ux/03` ("Suelta para añadir"), "Elegir archivo…" (foco inicial) con `sistema.elegirArchivoAudio()`.
- [ ] Soltar o elegir → "Leyendo el audio…" con el nombre, barra indeterminada y "Cancelar" (`fuente.cancelarImportacion`); al terminar, formulario D con "✓ Audio leído: {nombre} · {duración}", Título (obligatorio, "Escribe un título.", foco con el texto seleccionado), Artista, Álbum (ayuda), máx. 200, recorte; aviso `add.aviso.larga` si dura > 10 min con `runtime.estimarSeparacion`.
- [ ] "Continuar" (o Intro en el último campo) → `fuente.confirmarArchivo` → navega a `{ tipo: 'cancion', id, paso: 'progreso' }` (0045). "Cancelar", "‹ Biblioteca" y Esc (sin operación en curso) → `fuente.descartarImportacion` y Biblioteca; Esc con lectura en curso la cancela (criterio 14).
- [ ] Errores con su texto `add.error.*` (`FORMATO_NO_SOPORTADO`, `AUDIO_DEMASIADO_CORTO`, `SIN_ESPACIO`, genérico con "Copiar detalles") como banner `role="alert"` en la zona de arrastre, con el foco en el mensaje y la zona disponible para elegir otro archivo.
- [ ] Varios archivos soltados → toast "Añade las canciones de una en una." y se usa el primero. Soltar en la Biblioteca (0020) navega a esta vista con `archivo` y empieza la lectura automáticamente.
- [ ] **Paso 1 de una canción existente** (`paso: 'fuente'`, fuente completada): resumen (nombre del archivo o enlace + miniatura si hay, duración), formulario D con autoguardado al salir de cada campo (`biblioteca.actualizarMetadatos`) y mensaje "Guardado"; nota `add.resumen.nota`. No permite cambiar el audio (criterio 12).
- [ ] Tests de componente (API falsa): foco inicial; lectura y cancelación; formulario y validación del título; aviso de canción larga; cada error; varios archivos; archivo recibido desde la Biblioteca; resumen con autoguardado; Esc en cada estado.

## Notas de implementación
- **Qué se hizo**: `app/src/renderer/src/vistas/anadir/`: `AnadirCancion.tsx` (modo nueva, con `CabeceraCancion` de 0043 en modo `null`, selector de origen y panel), `PanelArchivo.tsx` (zona de arrastre 640 x 240 con "Suelta para añadir", "Elegir archivo…", lectura con barra indeterminada y Cancelar, formulario D, aviso de canción larga, errores `add.error.*` en `role="alert"` con el foco en el mensaje y la zona disponible, varios archivos -> toast, archivo recibido de la Biblioteca -> lectura automática), `CamposDatos.tsx` (título/artista/álbum comunes), `ResumenFuente.tsx` (paso 1 de una canción existente: resumen, autoguardado al salir de cada campo con `actualizarMetadatos`, "Guardado", nota `add.resumen.nota`; miniatura o marcador 160 x 90), `textos.ts`, `anadir.module.css` y tests. `App.tsx` monta `AnadirCancion` para `anadir` y `ResumenFuente` para `{cancion, paso:'fuente'}`; se actualizó `App.test.tsx`.
- **Decisiones**: (1) **Cifra del aviso de canción larga**: `runtime.estimarSeparacion` (0036) no existe; se usa la opción conservadora, `Esta canción dura {duración}. Separarla tardará más de lo normal.` sin el "(unos {n} minutos en tu equipo)". `textoLarga(duracion, minutos)` ya admite la cifra: al integrar 0036 basta pasarla. (2) **Estructura para 0051**: `ORIGENES` en `AnadirCancion.tsx` solo tiene "Archivo"; el selector (`ControlSegmentado`) y el `h2` "¿De dónde sale la canción?" se muestran cuando haya más de un origen; 0051 añade `{valor:'youtube'}` y renderiza su panel junto a `PanelArchivo`. El origen se recuerda en la sesión. `ResumenFuente` deja un comentario donde irán el wireframe E y los banners de YouTube (pendiente/error/interrumpido); hoy solo trata el error de una fuente de archivo ("Elegir otro archivo" -> `anadir` con `iniciales`). (3) Con `iniciales` (sustituir la fuente de la misma canción) el formulario conserva sus metadatos (no los de la heurística) y se llama a `confirmarArchivo(id, meta, { cancionId })`; la cabecera sigue en modo "Nueva canción". (4) Esc: listener en captura que cancela la lectura o vuelve a la Biblioteca, también con el foco en un campo de la propia vista (el foco inicial del formulario D es un campo); un campo de texto ajeno a la vista conserva su Esc. (5) Intro en Título y Artista pasa al campo siguiente; solo en Álbum envía. (6) La importación pendiente se descarta al desmontar la vista (Cancelar, ‹ Biblioteca, Esc, atajos); tras confirmar no. Las lecturas canceladas que aún terminan se descartan (patrón de generación, compatible con StrictMode). (7) El `h1` es "Añadir canción" (`TITULOS_VISTA`) y la cabecera pone "Nueva canción". (8) Un formato no admitido soltado sobre esta vista no se filtra por extensión: lo decide main (`FORMATO_NO_SOPORTADO`).
- **Cómo probarlo** (desde `app/`): `npx vitest run src/renderer/src/vistas/anadir src/renderer/src/App.test.tsx` (26 tests nuevos: foco inicial, lectura y cancelación, formulario y título, aviso largo, errores, varios archivos, archivo de la Biblioteca, `iniciales`, resumen con autoguardado, Esc); `npm run lint && npm run typecheck && npm run format:check && npx vitest run && npm run build && npx playwright test` (todo en verde); a mano `npm run dev` y arrastrar un audio sobre la Biblioteca (requiere el runtime/worker).
- **Deuda técnica**: sin E2E del flujo (0046; faltará un doble del selector de archivo); la cifra de estimación (0036); la pestaña y el paso 1 de YouTube (0051); sin revisión visual en ventana real; no se muestra el nombre del archivo con tooltip si es muy largo (solo elipsis).
